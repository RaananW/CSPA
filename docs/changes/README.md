# Change notes (closed)

**New changes no longer go here.** A pull request that changes a package adds a changeset
(`npm run changeset`), which becomes that package's `CHANGELOG.md` entry; see
[releasing](../releasing.md).

The files in this directory are the notes written before Changesets, one per pull request. They are
kept as history: they record the upstream checks (WICG proposal SHA, tracker access, browser build)
behind each change. Each package's `0.1.0` changelog entry summarizes them.
