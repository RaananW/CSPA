# Archived phase scripts

These scripts are historical report assemblers and measurement runners from
earlier phases. They are unmaintained, are not run by CI, the root
`package.json` scripts or the test suites, and are kept only for provenance.
They may depend on archived inputs that are not present in the lean checkout.
Do not use them to regenerate accepted reports; see
[docs/archive/history.md](../../docs/archive/history.md) and
[docs/archive/archive-catalog.md](../../docs/archive/archive-catalog.md).
