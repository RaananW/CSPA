Add the Strata Knob, the first Instrument-level component, to the private @underglass/ui package: a native range input over a printed dial with drag, ring click-to-set, cap taps, the wheel and a double-click reset (`attachStrataKnobs` in `/dom`), `knob.*` and `size.knob` tokens, the CSS recipe, React, Vue and Astro components, and Relief and Objects presentation on the GPU.
