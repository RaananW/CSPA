Strata look prototypes

Three candidate looks, side by side, each shown three ways. Relief: the GPU lights flat native controls (the default level). Objects: the same controls as 3D meshes (opt-in level). CSS only: the fallback without GPU. Light from the top left, the same palette and layout everywhere: only how physical it feels changes. Every control is real: type, toggle, hover, press, Tab. These are rough prototypes, not components.
